## 2026-05-14 - Clipboard Feedback Pattern
**Learning:** Providing immediate visual feedback (icon swap) and a success toast for clipboard actions significantly improves user confidence that the action succeeded, especially on mobile where native clipboard feedback might be subtle.
**Action:** Always implement a temporary icon swap (e.g., Copy to Check) and a toast notification when adding copy-to-clipboard functionality.
